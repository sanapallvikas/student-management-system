# Student Management System

## About
A simple Student Management System developed using C++. This project demonstrates basic programming concepts and helps manage student-related information.

## Technologies Used
- C++
- Basic programming concepts

## Project Files
- `main.cpp` — C++ source code.
- `main.exe` — Compiled executable file.

## Key Concepts
- Input and output
- Variables and data types
- Conditional statements and loops
- Basic program logic

## How to Run
1. Download or clone this repository.
2. Open `main.cpp` in a C++ IDE or code editor.
3. Compile the program using a C++ compiler.
4. Run the compiled program.
